# PediPOS

Punto de venta para colmados, mini markets y almacenes. Funciona sin internet, vende por voz con IA y suma el ITBIS 18%.

- Panel de talonario con ITBIS, buscar, lista de pedido con IA (DeepSeek via Puter) y venta por voz
- Catalogo, historial, analitica y soporte
- Todo se guarda en el telefono y se sincroniza solo con la base central cuando hay red
